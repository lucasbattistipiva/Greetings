# 👋 Greetings

Um projeto desenvolvido com **React.js e Next.js** para praticar os fundamentos do desenvolvimento de interfaces com componentes, estados e hooks.

## 🚀 Sobre o projeto

O Greetings é uma aplicação simples que exibe uma saudação dinâmica de acordo com o horário atual, além de apresentar a data e um relógio atualizado em tempo real.

O projeto foi criado com o objetivo de colocar em prática os conceitos fundamentais do React e explorar recursos do Next.js.

## 🛠️ Tecnologias utilizadas

- **Next.js** — Framework React.
- **React.js** — Biblioteca para construção de interfaces.
- **TypeScript** — Tipagem estática.
- **Tailwind CSS** — Estilização da interface.

## ✨ Funcionalidades

- Saudação dinâmica conforme o horário:
  - 🌅 Bom dia!
  - ☀️ Boa tarde!
  - 🌙 Boa noite!
- Relógio digital atualizado em tempo real.
- Exibição da data atual em português.
- Botão para iniciar e pausar o relógio.
- Interface responsiva.

## 📚 Conceitos praticados

- Componentes funcionais.
- JSX e TSX.
- Hooks do React (`useState` e `useEffect`).
- Renderização condicional.
- Manipulação de datas com JavaScript (`Date` e `Intl.DateTimeFormat`).
- Gerenciamento de intervalos com `setInterval` e `clearInterval`.
- Estilização com Tailwind CSS.

## 💻 Como executar o projeto

**1. Clone o repositório**

```bash
git clone https://github.com/lucasbattistipiva/Greetings.git
```

**2. Acesse a pasta**

```bash
cd Greetings
```

**3. Instale as dependências**

```bash
npm install
```

**4. Execute o servidor de desenvolvimento**

```bash
npm run dev
```

**5. Acesse no navegador**

```text
http://localhost:3000
```
